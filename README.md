# Frontend Todo

1인 SaaS 창업 교육 과정에서 제공한 Frontend 할 일 관리 프로젝트를
기반으로 과제 및 선택 과제 기능을 구현한 저장소입니다.

## 구현 내용

- TypeScript를 활용한 할 일 및 테마·필터 타입 정의
- Firebase Firestore를 이용한 할 일 추가, 조회, 수정 및 삭제
- 실시간 목록 동기화 및 최신순 정렬
- 할 일 완료·미완료 상태 전환
- 전체·진행 중·완료 필터링
- 완료된 할 일만 표시하는 페이지
- Redux Toolkit을 활용한 테마 및 필터 상태 관리
- 라이트·다크 모드 전환
- 새로고침 시 테마 및 필터 설정 유지
- 테마와 필터 상태 및 변경 함수를 묶은 커스텀 훅
